# Documentation Guide

This directory contains the public documentation for how the Request Tracing Lab grows from a single Flask application into a production-systems troubleshooting environment.

## Public documentation

- [`learning-path.md`](learning-path.md) — the staged technical curriculum
- [`implementation-roadmap.md`](implementation-roadmap.md) — what will be added and in what order

## Private documentation

The following paths are intentionally ignored by Git and are meant to stay local unless you later decide to publish them:

```text
docs/project-evolution.md
docs/learning-journal/
docs/interview-reflections/
```

These private files can be used to record:

- how your technical reasoning changes over time
- lessons from interviews or incident exercises
- areas that felt difficult
- improvements in how you structure explanations
- personal journal entries and confidence notes

The public project should demonstrate the engineering work. The private journal can document the personal journey behind it.
