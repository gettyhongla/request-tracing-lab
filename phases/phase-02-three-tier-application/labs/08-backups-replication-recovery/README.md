# 08: Backups, Replication, And Recovery

Goal:

```text
Explain how production data is protected and recovered.
```

Evidence Tasks:

* Define RPO and RTO.
* Explain backup versus replication.
* Explain read replica lag.
* Explain Multi-AZ failover at a high level.
* Define restore-test evidence.

Questions:

```text
How much data can the business afford to lose?
How long can the database be unavailable?
When was the last successful backup?
When was the last restore test?
What happens to reads during replication lag?
What happens to writes during failover?
```

Completion standard:

```text
You can explain whether the database recovery plan is proven or just assumed.
```
