# 06: Transactions And Locks

Goal:

```text
Understand how database concurrency can cause slow or failed requests.
```

Evidence Tasks:

* Explain what a transaction protects.
* Explain row locks and blocking.
* Identify symptoms of lock contention.
* Identify a deadlock scenario.
* Decide what mitigation is safe during an incident.
