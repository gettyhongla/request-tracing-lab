# Phase 4: Observability

Phase 4 turns request logs into correlated telemetry.

Focus:

* Structured JSON logs
* Request IDs, trace IDs, and span IDs
* Prometheus metrics
* OpenTelemetry traces
* Grafana dashboards
* RED and USE methods
* Alert thresholds and escalation evidence

Completion standard:

```text
Given a symptom, use logs, metrics, traces, and dashboards together to identify the failing layer and explain the supporting evidence.
```
