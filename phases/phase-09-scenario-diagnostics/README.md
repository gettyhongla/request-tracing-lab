# Phase 9: Scenario Diagnostics

Phase 9 removes hints. You investigate scenarios without being told which component is broken.

Each scenario tests whether you can:

1. Ask precise scoping questions.
2. Build and rank hypotheses.
3. Use evidence to eliminate causes.
4. Explain findings clearly to customers and engineers.

Completion standard:

```text
Given a vague symptom, produce a structured investigation, identify the failed layer, explain the supporting evidence, and communicate the incident at the right depth for the audience.
```
