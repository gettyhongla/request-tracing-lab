# 06: Release Management

Goal:

```text
Understand how deployment changes become repeatable, reviewable, and reversible.
```

Evidence Tasks:

* Identify which values differ by environment.
* Render or inspect manifests before deploying.
* Record what version is running.
* Record what configuration was used.
* Define a rollback plan before deployment.
* Decide whether to promote, pause, roll back, or roll forward.

Release questions:

```text
What changed?
Who approved it?
Which version is running?
How do we know it is healthy?
How do we roll back?
What evidence proves the release caused or did not cause an issue?
```

Completion standard:

```text
You can explain a release as an operational event, not just a command that was run.
```
