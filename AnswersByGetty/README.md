# Answers By Getty

This directory contains Getty's completed lab work, investigation notes, deployment evidence, design reviews, RCA writeups, and reflections.

The `phases/` folders teach the process. `AnswersByGetty/` should only show completed evidence and conclusions from work that has actually been done.

## Answer Sets

```text
AnswersByGetty/

|-- phase-02.md

`-- assets/

    |-- phase-02/
    `-- phase-03/
```

## Evidence Standard

Each completed answer should show:

* What I observed
* What evidence I collected
* What I ruled out
* What I concluded
* What I would do next in production
* What concept I want to retain for future phases

Keep timestamps, request IDs, cookies, and tokens realistic, but redact secrets and personal notes that do not belong in a public repository.
